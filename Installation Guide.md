# Installation

## Prerequisites

Before using this workflow, ensure you have the following:

- n8n (self-hosted or cloud)
- An OpenRouter account with an API key
- A Google account
- Gmail API credentials
- Google Sheets API credentials
- A Tally account

---

## Clone the Repository

```bash
git clone https://github.com/YOUR_USERNAME/medical-thesis-proposal-writer.git
```

---

## Import the Workflow

1. Open your n8n instance.
2. Select **Import Workflow**.
3. Import the JSON workflow located in:

```
workflow/Medical Thesis Proposal Writer.json
```

---

## Configure Credentials

Configure the following credentials inside n8n.

### OpenRouter

Create an HTTP Request credential containing:

- Base URL
- API Key

---

### Gmail

Connect your Gmail account using OAuth2.

Required permissions:

- Send Email

---

### Google Sheets

Connect your Google account.

The workflow requires access to:

- Read Spreadsheet
- Append Rows
- Update Rows

---

### Tally

Create your Tally form.

Ensure the webhook URL generated by n8n is connected as the form submission endpoint.

---

## Environment Variables

Configure the following variables.

| Variable | Description |
|-----------|-------------|
| OPENROUTER_API_KEY | OpenRouter API Key |
| GOOGLE_SHEET_ID | Spreadsheet ID |
| GMAIL_ACCOUNT | Gmail account used for delivery |
| TALLY_WEBHOOK | Tally webhook URL |

---

## Test the Workflow

1. Submit the Tally form.
2. Confirm the workflow starts.
3. Verify that:
   - Proposal is generated.
   - DOCX is created.
   - Email is sent.
   - Google Sheets entry is created.
